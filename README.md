# 🌐 First 3D

A small 3D rendering project built as my first steps into learning 3D development. This is a place for me to experiment with Three.js, follow tutorials, and learn how to create and animate 3D objects in the browser.

## 🎮 About the Project

This project is my introduction to 3D rendering on the web using Three.js. I'm starting with the basics, including creating a 3D scene, setting up a camera, adding objects, and animating them.

This is an ongoing learning project, so I'll continue experimenting with different ideas and building on what I learn as I become more comfortable with 3D development.

## 🛠️ What I'm Learning

Through this project, I'm exploring the fundamentals of 3D rendering, including:

- Creating 3D scenes, cameras, and renderers
- Working with geometries, materials, and meshes
- Animating 3D objects with JavaScript
- Understanding how Three.js works in the browser
- Using Vite to run and develop a project locally

## 🚀 Future Improvements

Some things I'd like to experiment with as I learn more:

- Creating different 3D objects and shapes
- Experimenting with materials, colors, and lighting
- Learning more about camera positioning and movement
- Building more complex 3D scenes
- Exploring animations and interactive 3D experiences

## 📚 Why I Built This

Most of my development experience so far has been focused on web development, using technologies like JavaScript, React, and Next.js. I wanted to try something different and start learning how 3D rendering works.

I'm using this project to learn by doing, follow tutorials, experiment with new concepts, and gradually build my understanding of 3D graphics on the web.
